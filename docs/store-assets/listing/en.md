# Chrome Web Store listing — English

## Name

Regex URL Guard

## Summary

Block distracting websites with customizable regular expression URL rules.

## Detailed description

Regex URL Guard helps you stay focused by controlling when and for how long distracting websites can be opened. Match complete domains or use JavaScript regular expressions for precise URL targeting, then organize related sites into reusable groups.

For each group, combine rules that:

- Block access during selected times
- Set a daily browsing-time limit
- Add a wait before access is granted
- Show the built-in blocked page or redirect to another URL

Use Lock Mode when you want relaxed restrictions to wait until the next rule day. You can also pause an eligible group after a configurable countdown, check current limits from the toolbar popup, and receive a notification before daily time runs out.

Additional features:

- Blacklist and whitelist matching
- Schedules by day, date, or recurring period
- Clear handling of overlapping rules
- English and Japanese interfaces
- Light, dark, and automatic themes
- JSON settings import and export
- Remaining-time badge and notifications

Browsing time is counted only while Chrome is focused and a matching page is active in the current tab. Settings are stored with Chrome extension storage and the extension does not collect or transmit browsing data.
