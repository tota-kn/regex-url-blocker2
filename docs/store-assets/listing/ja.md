# Chrome Web Store 掲載文 — 日本語

## 名前

Regex URL Guard

## 概要

正規表現のURLルールで、気が散るウェブサイトへのアクセスを制限します。

## 詳細な説明

Regex URL Guardは、気が散るウェブサイトを開ける時間帯や利用時間を管理し、集中を保つための拡張機能です。ドメインをそのまま指定することも、JavaScriptの正規表現を使ってURLを細かく指定することもできます。関連するサイトはグループにまとめて管理できます。

グループごとに、次のルールを組み合わせられます。

- 指定した時間帯のアクセスをブロック
- 1日あたりの閲覧時間に上限を設定
- アクセス前に待機時間を設定
- 拡張機能のブロックページを表示、または別のURLへ移動

Lock Modeを使うと、制限を緩める変更を次のルール日まで保留できます。許可されたグループは設定したカウントダウン後に一時停止でき、ツールバーのポップアップでは現在の制限を確認できます。日次上限が近づいたときの通知にも対応しています。

そのほかの機能：

- ブラックリストとホワイトリスト
- 曜日、日付、繰り返し期間によるスケジュール
- 重複するルールの適用内容を分かりやすく表示
- 英語と日本語のインターフェース
- ライト、ダーク、自動テーマ
- JSON形式での設定のインポートとエクスポート
- 残り時間のバッジ表示と通知

閲覧時間は、Chromeにフォーカスがあり、対象ページが現在のタブで開かれている間だけ加算されます。設定はChromeの拡張機能ストレージに保存され、閲覧データを収集または外部送信することはありません。
