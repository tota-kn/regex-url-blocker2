# Changelog

## 1.5.0

### Added

- 時間ウィンドウ・制限・遷移先を 1 組にまとめた Rule を導入し、「いつ・何を・どこへ」を 1 行で読めるようにしました。ルールは評価順（Block → Daily limit → Wait）に並べ替えて表示するため、画面の並びと実際の適用順が一致します。
- ルールの時間帯が重なっている場合に、保存を妨げない警告を表示するようにしました。
- Lock Mode 中に削除したことで希望設定から消えたものの、次の rule day まで制限が有効なまま取り残されたグループを、同じ ID のまま保存設定へ戻せる Restore 操作を追加しました。
- Roboto Mono を同梱し、拡張機能全体のタイポグラフィを統一しました。

### Changed

- `timeWindows` と `restrictions` の 2 リストを直積で適用する方式を廃止し、Rule の組へ置き換えました。あわせて redirect を block の遷移先オプションへ統合し、グループとグローバル設定の `blockAction` / `redirectUrl` を削除しました。旧形式の設定は読み込み時に自動移行します。
- 利用時間の加算を daily limit ルールが有効な間だけに限定し、後の時間帯に予定されたルールの枠を前もって消費しないようにしました。
- 一時停止（Pause）が block だけでなく待機ゲートも解除するようにしました。
- 時間帯付き Daily limit の解除時刻を、ウィンドウ終了と日次リセットの早い方として扱うようにし、ブロックページの表示を `Unblocks at` / `Resets at` で出し分けるようにしました。
- Daily limit の最小値を 1 分にしました。0 分は Block と実挙動が同じで解除の意味論だけが異なる紛らわしい設定だったため、保存済みの 0 分と旧 grace の 0 分は Block ルールへ自動移行します。
- グループカードから「RIGHT NOW」要約、Earlier restrictions バナー、Active settings ダイアログを削除し、保留中の設定の告知をフィールド単位の注記へ一本化しました。現在の適用状況の要約は Popup の役割としました。
- 設定エクスポートのスキーマバージョンを `12` に更新し、`2`・`3`・`4`・`11` の import 互換を維持しました。
- 制限まわりの UI 文言を Restriction 系の用語へ統一しました。

### Removed

- Session limit 種別を削除しました。壁時計ベースの計測で離席中も枠を消費するため不正確で、Wait の許可時間と役割が重複していたため、Daily limit（総量）と Wait（入場摩擦）の 2 軸へ集約しました。保存済みの session limit ルールは読み替えずに破棄し、`storage.local` の `sessionLimitState` も削除します。

### Fixed

- Pause 設定のバリデーションエラーが横並びのラベル行の内側に挿入され、レイアウトが崩れていた問題を修正しました。

## 1.4.0

### Added

- 制限（Restriction）に「redirect」（指定 URL への遷移）と「wait」（アクセス前の待機ゲート）種別を追加し、block・grace と合わせて時間帯ごとに柔軟に組み合わせられるようにしました。
- 待機ゲート通過後、指定した分数だけアクセスを許可する Wait 画面を追加しました。
- ブロックページに、現在適用されているブロック理由と解除時刻を表示するようにしました。
- グループ設定の保存時に、URL pattern・時間ウィンドウ・制限のいずれかを1つ以上設定することを必須とするバリデーションを追加しました。
- フォーム項目の編集状態に応じてバリデーションメッセージの表示タイミングを制御する仕組みを追加しました。
- 以前の制限が次の rule day まで有効な場合、グループカードにその旨と反映日時を表示し、現在の有効設定を確認できるようにしました。
- グループごとに一時停止（Pause）を禁止できる設定（Allow Pause）を追加しました。禁止すると Pause 操作が無効になり、実行中の一時停止も解除されます。Lock Mode 中は禁止が即時に反映され、再許可は次の rule day まで遅延します。

### Changed

- `restrictionRules` を `restrictions` にリネームし、制限の時間条件を独立した `TimeWindow`（常時 / スケジュール）として整理しました。
- 制限編集 UI を刷新し、旧 `LimitRulesEditor` を `RestrictionEditor` / `RestrictionRulesEditor` / `ScheduleWindowEditor` に置き換えました。
- グループの遷移先設定（Page shown when blocked / URL pattern match behavior）の options UI を廃止し、redirect は制限単位の設定に統合しました。既存データとの後方互換は維持しています。
- URL pattern 追加ボタンのクリック処理を簡略化しました。

### Fixed

- E2E テスト基盤を強化（service worker fixture、storage 変更のポーリング待機など）し、restrictions 構造の変更に追随してテストを更新しました。

## 1.3.0

### Added

- グループを一時停止とは別に無効化できる機能を追加しました。
- Options 画面のグループカードにアクションメニューを追加し、一時停止、無効化、削除の操作を整理しました。
- Popup で対象グループのブロック状態、一時停止状態、ブロック時間帯、日別上限の状態を表示できるようにしました。
- 一時停止の待機中、準備完了、一時停止中を Popup 表示向けに判定するユーティリティを追加しました。

### Changed

- 無効化されたグループを URL 判定、counter、通知、redirect URL 判定の対象から除外するようにしました。
- Options 画面のグループ状態表示に Disabled badge と無効化状態の要約を追加しました。
- Popup の空状態文言を、日別上限だけでなく有効な制限全体を表す内容に変更しました。
- Daily limit の表示を調整し、上限が設定されている場合だけ `min/day` を表示するようにしました。
- 設定エクスポートのスキーマバージョンを `4` に更新し、`2` と `3` の import 互換を維持しました。

### Fixed

- 無効化グループが閲覧時間 counter や最小残り時間の判定に残らないようにしました。
- グループ無効化、一時停止表示、Popup 状態表示、ブロック判定、ストレージ互換のテストを追加・更新しました。

## 1.2.0

### Added

- グループ単位でブロックを一時停止できる機能を追加しました。
- 一時停止リクエスト後にカウントダウンダイアログを表示し、待機完了後に一時停止を開始できるようにしました。
- 一時停止中のグループに残り時間を表示するようにしました。
- `groupPauseState` の保存仕様を追加し、期限切れや不正な runtime 状態を安全に除外するようにしました。
- 通知計画のユーティリティを追加し、残り時間通知、対象ページを開いた時の通知、redirect ブロック通知の判定を整理しました。
- 仕様ドキュメントを `docs/spec/` 配下に整理し、ストレージ、UI、権限、非要件の記述を追加しました。

### Changed

- Options 画面のグループカード、グローバル設定、URL pattern、Daily limit、Blocked time、通知設定の表示文言をより明確にしました。
- グループ編集時の Options 項目を折りたたみ表示にし、通常表示では重要な設定だけを要約するようにしました。
- URL pattern の placeholder を具体的な例に変更しました。
- 空の URL patterns 状態でも追加ボタンを表示するようにしました。
- Active settings とグループカードに読み取り専用表示を追加しました。
- 一時停止リクエストのボタンラベルを `Request pause` に変更しました。
- 通知履歴の更新処理を共通化し、同一グループ・同一論理日の重複通知を抑制する処理を整理しました。
- `Blocked time` と `Daily limit` の表記を統一し、設定項目名を読み取りやすくしました。

### Fixed

- ボタンの不要な focus style 指定を削除し、表示を調整しました。
- グループ、日時、通知、ストレージ、ブロック判定まわりのテストを追加・更新しました。
